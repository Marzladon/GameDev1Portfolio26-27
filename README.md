## How To Run
Built With Processing.
Processing version:
Main sketch and project folder: Intergalactic_Junkyard
Required Libraries: Gifanimation and sound.

## Controls
MouseX - Move Ship
MouseClick - Fire Laser

## Gameplay
Shoot the start button to start.
Then try to shoot the scraps or hit it with your ship in an emergency.
Try not to let the scraps pass the ship.
Barrels are powerups, H gives the ship health and D gives temporary Turret buffs.
